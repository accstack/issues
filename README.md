# ACCSTACK: corrections and questions

This repository holds the issue tracker for [accstack.org](https://accstack.org): the catalog of word stress and tone, its bibliography, and Typotron.

To report an entry that says something its source does not, a missing source, a bibliography error, or a Typotron problem, [open an issue](../../issues/new/choose) and pick the matching form. One language per issue. If you would rather write, send the same information to comments@accstack.org.

The site is maintained by Matthew Schwartz, Kevin Ryan, Matthew Gordon and Joe Pater. Funding for AccStack was provided by Anthropic. AccStack is not an Anthropic project.
